The `targetNode` option of `injectStylesheet()` accepts a shadow root, so stylesheets can be scoped to a web component instead of leaking into `document.head`.

The same applies to `stylesheetsLocation` in `loadCKCdnResourcesPack()` and to `injectedStylesheetsLocation` in `loadCKEditorCloud()`, which pass the location down to every stylesheet of the loaded pack. The `InjectStylesheetLocation` type is now exported from the package.
