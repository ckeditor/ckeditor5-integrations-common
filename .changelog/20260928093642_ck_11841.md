Added support for Trusted Types when loading CKEditor 5 from CDN. Script URLs injected by the integration are now signed with a Trusted Types policy, so the editor can be loaded on pages that enforce the `require-trusted-types-for 'script'` Content Security Policy directive.

By default, the integration creates a policy named `ckeditor5-integrations`. If your CSP restricts policy names with the `trusted-types` directive, add this name to the list, for example: `trusted-types ckeditor5-integrations`. The default policy accepts only `http:` and `https:` script URLs (including relative ones) and refuses any other protocol, such as `javascript:` or `data:`.

If your application already has its own policy, you can pass it using the `trustedTypePolicy` option. In such a case, the integration uses your policy and does not create the default one.
